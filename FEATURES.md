# Feature inventory

## Status definitions

- `DOCUMENTED`: requirements/contracts exist, but no executable feature exists.
- `PLANNED`: mapped to a known roadmap phase but not implemented.
- `PARTIALLY_VERIFIED`: implementation exists and local checks pass, but a required external integration gate was not run.
- `UNMAPPED`: the original Phase 4–15 scope is unavailable, so an authoritative phase mapping cannot be asserted.
- `IMPLEMENTED`: code exists and every required phase verification gate has passed.
