# Feature inventory

## Phase 8E implemented subset

- Start/poll/cancel a protected two-date spectral-change job for the selected AOI and chronological supported pair.
- Inspect computed changed area, joint-valid observed denominator, observed coverage, unknown area, alignment and warnings.
- Toggle an authorized aligned categorical overlay with legend and display-only opacity; changing AOI/pair clears it.
- Route bounded “What changed?” prompts to the current computed result, never to single-image model inference.

## Status definitions

- `DOCUMENTED`: requirements/contracts exist, but no executable feature exists.
- `PLANNED`: mapped to a known roadmap phase but not implemented.
- `PARTIALLY_VERIFIED`: implementation exists and local checks pass, but a required external integration gate was not run.
- `UNMAPPED`: the original Phase 4–15 scope is unavailable, so an authoritative phase mapping cannot be asserted.
- `IMPLEMENTED`: code exists and every required phase verification gate has passed.
