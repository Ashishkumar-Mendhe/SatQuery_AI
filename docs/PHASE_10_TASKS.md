## 10A+B work log — 2026-09-26

Implemented `GeoAgentMessageRequest`/`GeoAgentMessageResponse`, strict selected-scene/dependency/tool-reference schemas, and a pure deterministic `route_message`. The request binds UUID request/conversation IDs, ≤1,000 visible characters, the validated AOI and ≤2 distinct stable optical/SAR identities with optional UTC acquisition and actual selected SAR polarization. The response records status, intended analysis, ordered source IDs, proposed allow-listed tool, missing inputs, dependency states, user explanation, and an explicit `not_started` execution state. A `completed` response cannot exist without actual matching tool result references. Arbitrary client URL/path identities, duplicates, extra confidence/readiness claims and non-UTC dates fail validation; a selected but unsupported NISAR scene receives an explicit `unsupported` route outcome rather than being confused with Sentinel-1 C-band.

Routing recognizes VQA, caption, referring grounding, chronological same-sensor optical change, source-separated optical/SAR observation, and draw/zoom/clear AOI instructions. It asks for a missing AOI, scene, date, SAR polarization, or named feature; it does not guess. Cross-sensor change/grounding, object counts, causal claims and confidence are not sent to single-image VQA. A structurally complete route is `plan_ready`, **not** scientific readiness or job execution. Runtime dependency availability is `unknown` unless a trusted server-side snapshot says otherwise; map control reports `unavailable` because it is not connected. The Phase 7 provider is not used for routing because it is not configured in the recorded environment and a deterministic route is sufficient for this bounded vocabulary; no LLM, public API route, job, persistent conversation, model call, map mutation, or frontend change was added.

## 10C work log — 2026-09-26

Added a seven-entry closed tool registry with existing strict input schemas (tile metadata, Phase 7 inference, Phase 8 preparation/change, Phase 9 optical/SAR) plus a typed map-action input. Each entry records scene count, AOI need, bounded submission timeout (2–20 seconds), and cancellation support. The protected `POST /api/v1/geoagent/execute` route resolves a verified `ProcessingPrincipal` before dispatch, re-routes the validated request server-side, builds fixed allow-listed arguments, and calls the existing imagery tile-metadata or owner-scoped job service methods. Its tool output is the **actual** tile metadata, job status, or committed result; queued jobs return real job IDs and existing protected cancel paths, not an invented answer. Repeated requests use the same owner-scoped service idempotency key derived from request UUID and tool; a timed-out submission requires retrying the same request ID. A successful cached job is read through the existing result API before exposing a result ID. The execution summary retains intent, tool, selected stable scene IDs, a SHA-256 of the validated AOI serialization when present, state and actual job/result IDs; the response includes a safe error code where applicable. No credentials or provider URLs enter the summary.

Supported dispatch: `imagery_tiles` for display-only Sentinel-2 imagery; `inference_vqa`, `inference_caption`, `inference_grounding` through Phase 7; `optical_change` through Phase 8 with server-refetched before/after acquisition order; `optical_sar_observation` through Phase 9 with the one existing fixed separate-source question and selected real polarization. Source identity, AOI, text size, bands, 10 m optical grid, 20 m optical/SAR grid, and 100,000-pixel optical-change request ceiling are validated by the reused contracts/services. Phase 6/8/9 quality and raster/provider checks still happen in their workers. There is no new detector, model fallback, output normalization, or fabricated measurement. Map/AOI commands remain **unavailable** from this backend route: the working editor/navigation is browser-local and no safe backend-to-map action bridge exists until authorized 10E. This limitation is returned explicitly, not called a successful map action.
